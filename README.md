# 💊 موقع توصيل الأدوية

تطبيق ويب عربي (RTL) لتوصيل الأدوية مبني بـ HTML/CSS/JavaScript خالص بدون أي مكتبات خارجية.

## المميزات

- 🔍 بحث فوري في الأدوية
- 🗂️ تصنيفات (مسكنات، مضادات حيوية، فيتامينات، عناية بالطفل، أدوية مزمنة)
- 🛒 سلة مشتريات كاملة مع إدارة الكميات
- 📦 إتمام الطلب مع بيانات العميل والعنوان وطريقة الدفع
- 📜 سجل الطلبات (محفوظ محلياً)

## التشغيل

افتح `index.html` في المتصفح مباشرة، أو:

```bash
python3 -m http.server 8000
```

## الهيكل

```
index.html      # الصفحة الرئيسية
css/style.css   # التنسيقات (تصميم متجاوب)
js/data.js      # بيانات الأدوية
js/app.js       # منطق التطبيق
```

مشروع مفتوح المصدر مستوحى من منصات توصيل أدوية مشابهة.
